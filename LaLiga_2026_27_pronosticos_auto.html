Cómo se calcula el pronóstico

Cuando existen partidos disputados, se ponderan rendimiento general, rendimiento local/visitante, goles a favor y en contra y ventaja de campo. Al inicio de temporada, cuando todos los equipos tienen 0 partidos, se utiliza una valoración inicial para evitar porcentajes artificialmente idénticos. Las lesiones y sanciones requieren una fuente específica de disponibilidad; no se inventan datos si la API no los proporciona.
